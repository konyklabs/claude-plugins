## 17. Silently skipped test tiers

**What happened.** A credentialed tier (live sandbox, e2e) skipped when its
secrets were absent. The tick was green. Nothing had run.

**Rule.** Require credentials everywhere they are expected; skip only where
the platform withholds them by design (pull requests from forks), and fail
loudly otherwise:

```python
@pytest.fixture(scope="session")
def sandbox_token():
    token = os.environ.get("SANDBOX_TOKEN")
    if not token:
        if os.environ.get("GITHUB_EVENT_NAME") == "pull_request" and os.environ.get("FORK_PR") == "true":
            pytest.skip("fork PR: secrets withheld by the platform")
        pytest.fail("SANDBOX_TOKEN missing: this tier must run here")
    return token
```

The scanner lists env-conditioned skips and whether any workflow passes
secrets to jobs.

## 18. Committed contract artifacts drifting

A pact or snapshot file regenerated by the suite goes stale unless CI diffs
it: `git diff --exit-code pacts/` after the tests. The consumers verifying
against the committed artifact then verify against what the suite produces.

## 19. Action pinning and licensing

Third-party actions pinned to a tag or a branch change under you. Pin to
the 40-character SHA, with the tag in a comment. Several widely used
actions have relicensed to terms requiring a per-organization key; where
the action wraps a CLI, prefer the upstream CLI pinned by version *and*
checksum (`security-scanning/references/scanners.md` § 1). The scanner
lists every `uses:` with its pin type.

## 20. Dependency licence allowlist

Enforced as a test over the resolved lockfile, so an automated bump that
swaps a licence fails CI rather than shipping:

```python
ALLOWED = {"MIT", "BSD-3-Clause", "BSD-2-Clause", "Apache-2.0", "ISC", "PSF-2.0", "MPL-2.0"}

def test_dependency_licences_are_allowed():
    report = json.loads(subprocess.run(["pip-licenses", "--format=json"], capture_output=True, text=True, check=True).stdout)
    bad = [(r["Name"], r["License"]) for r in report if not any(a in r["License"] for a in ALLOWED)]
    assert bad == []
```

`pip-licenses` is a PyPI tool; pin it in the tool environment. The list
above is a placeholder; the organization's counsel owns the real one.

## 21. Runtime version pinning

CI, the devcontainer, the container image and the lockfile can each name a
different interpreter and nobody notices until a wheel is missing. The
scanner collects every declared version and fails on a mismatch. Fix: one
`.python-version`, read by the others, and a test that asserts
`sys.version_info[:2]` matches it.

## 22. Link checking

Published guide URLs move. Run `lychee` over the docs before a release;
it makes network requests, so it is a deliberate step, not part of the
offline scan.
